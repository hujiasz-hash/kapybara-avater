## 一、 角色设定与视觉 DNA (Character DNA)

OctoBara（章鱼水豚）是致敬 GitHub Mona Octocat 的极客开源吉祥物，将“情绪极度稳定”的水豚与“高并发多任务”的章鱼触手融合：

1. **头部与神态**：
   - 保留经典水豚方圆大吻部（Muzzle）与微眯小豆眼，传递“即使生产环境报警也波澜不惊”的淡定感。
   - 头顶佩戴标志性的**蜜柑小橘子（带斜上翘嫩绿叶片）**，作为全局视觉锚点与未来换装插槽。
2. **身体与触手**：
   - 躯干下部平滑过渡出 5 条柔软有力的章鱼触角。
   - 触手具备多任务能力：典型姿态为一手稳握 Git 陶瓷咖啡杯，一手在机械键盘上飞速敲击代码，其余触角呈稳定底座支撑。
3. **轮廓与线条**：
   - 外轮廓采用 12~16px 粗度的浓缩咖啡深棕色（Espresso Charcoal）闭合线条。
   - 贴纸版本附带统一宽度的圆形外扩纯白切模边缘（Die-cut Border）。

## 四、 响应式图标尺度降级规范 (LOD Iconography)

在小尺寸（如 16×16、32×32 网页 Favicon）下，直接等比缩放全身立绘会导致机械键盘与咖啡杯变成视觉噪点，挤压水豚大脸与头顶橘子的辨识度。因此建立三级响应式降级规范：

1. **LOD-1：macOS 桌面独立 App 图标 (512 ~ 1024 px)**
   - 文件：`07_octobara_app_icon_macos_squircle.jpg`
   - 构图：深空灰 Squircle（Apple 圆角矩形）底座 + 工程师对齐网格线。主体采用触手胸像（Bust Shot），3D 黏土微质感，橘子居中，左右触手环抱。
2. **LOD-2：系统菜单栏与工具栏图标 (48 ~ 96 px)**
   - 文件：`08_octobara_micro_bust_icon.jpg`
   - 构图：纯净特写胸像，剔除键盘与咖啡杯细碎杂物，强化五官与粗黑轮廓。
3. **LOD-3：极小网页 Favicon 与终端状态图标 (16 ~ 32 px)**
   - 文件：`09_octobara_scale_comparison.png`（多阶梯缩放验证效果表）
   - 构图：聚焦大脸与顶部橘子，两耳与下部触手提供对称轮廓，高反差色块填充，确保在浏览器标签页一眼识别。
