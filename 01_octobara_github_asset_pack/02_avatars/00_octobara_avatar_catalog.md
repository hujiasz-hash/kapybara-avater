## 二、 格式与多平台使用建议

1. **GitHub Profile / GitLab 头像**：
   - 推荐使用 `_512.png` 尺寸，圆形裁剪后边缘与背景比例经过黄金视觉微调，不会截断触手外沿。
2. **飞书 / 微信 / Slack 办公即时通讯**：
   - 可随工作状态自由切换头像（例如大促发布切 `02_心如止水`，排查故障切 `03_CPU烧了`，下班切 `06_准点下班`）。
3. **印刷与实体周边**：
   - 目录下同时保留 `_1024.jpg` 超清母版，适合制作成圆形徽章、胸针或冰箱贴。
